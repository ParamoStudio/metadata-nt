    Investigation Tripwire
    
          
    
            
    What is this?
    
            
    Plants a plausible Source reference inside the synthetic metadata. Reading the metadata does not trigger it. Following the reference does.
    
            
    What happens?
    
            
    Canarytokens.org sends an alert to the email you provide and redirects the visitor to the destination you selected.
    
            
    Privacy
    
            
    Your alert email is provided to Canarytokens.org so it can send notifications. It is not written into the file or exposed through the planted Source URL. For sensitive use, use a dedicated email alias or relay.
    
            
    What can an alert tell me?
    
            
    It means the planted URL was requested. Canarytokens may include network or request information such as the source IP observed by the service. That IP is not proof of a person's identity and may belong to a VPN, proxy, Tor exit, security scanner, gateway or other intermediary.
    
            
    False positives
    
            
    Link scanners, security gateways and automated analysis systems can sometimes follow URLs. A trigger does not prove who requested it.
    
            
    False negatives
    
            
    No alert does not prove that nobody inspected the file. Someone can read the metadata without following the link, work offline, block network requests or recognize the Canary infrastructure.
